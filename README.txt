LARAS PANGESTI — PERSONAL WEBSITE

Isi folder:
- index.html  : struktur dan isi halaman
- style.css   : tampilan maroon / wine / cherry
- script.js   : menu mobile, animasi saat scroll, dan navigasi aktif

CARA MENJALANKAN
1. Ekstrak file ZIP.
2. Buka folder laras_personal_website di Visual Studio Code.
3. Klik kanan index.html lalu pilih Open with Live Server, atau buka index.html langsung di browser.

BAGIAN YANG BISA KAMU GANTI
- Foto utama: ganti elemen .photo-placeholder di index.html dengan tag <img src="foto.jpg" alt="Foto Laras">.
- Foto galeri: ganti isi .gallery-placeholder dengan tag <img>.
- Nama sekolah, tahun pendidikan, email, dan username Instagram: sesuaikan teks/link di index.html.

Tema warna menggunakan wine gelap, maroon, dan cherry red. Website sudah responsif untuk desktop dan HP.
